# 📝 BlogPlatform — Полноценная платформа для блогинга

Добро пожаловать в **Blog Platform**! Это современное веб-приложение для ведения блогов, которое позволяет пользователям делиться своими мыслями, обсуждать статьи и находить интересных авторов. 

Проект поддерживает разделение ролей, систему лайков, подписок, вложенных комментариев, а также имеет удобную панель администратора.

---

## 🎯 Что можно делать на платформе?

Платформа предлагает широкий функционал в зависимости от вашей роли: Читатель, Автор или Администратор.

### 👀 Для Читателей (доступно всем)
*   **Просмотр ленты:** Читайте все опубликованные статьи на главной странице.
*   **Поиск и фильтрация:** 
    *   Ищите посты по ключевым словам в заголовке и тексте.
    *   Фильтруйте контент по категориям (например, «Наука», «Программирование») и тегам (например, #python, #react).
    *   Сортируйте посты: сначала новые, сначала старые или самые популярные (по количеству просмотров).
*   **Взаимодействие:** 
    *   Ставьте лайки понравившимся статьям.
    *   Оставляйте комментарии под постами.
    *   Отвечайте на комментарии других пользователей (поддерживается древовидная структура ответов).
*   **Подписки:** Подписывайтесь на авторов, чтобы не пропускать их новые публикации. В профиле автора отображается счетчик его подписчиков.
*   **Профили:** Переходите в профили других пользователей, чтобы посмотреть их биографию и список всех их постов.

### ✍️ Для Авторов
*   **Создание контента:** Пишите статьи с удобным и чистым интерфейсом.
*   **Оформление постов:** 
    *   Загружайте обложки для статей.
    *   Добавляйте краткое описание (подзаголовок) для привлечения внимания.
    *   Выбирайте категорию и добавляйте теги для лучшей навигации.
*   **Управление постами:** 
    *   Сохраняйте посты как черновики (видны только вам).
    *   Публикуйте статьи сразу или в нужный момент.
    *   Отправляйте устаревшие статьи в архив.
*   **Редактирование:** Изменяйте заголовки, текст, обложки и теги своих постов в любое время.
*   **Смена роли:** Любой зарегистрированный пользователь может стать Автором, просто переключив роль в настройках своего профиля.

### 🛡️ Для Администраторов
*   **Модерация:** Удаляйте или редактируйте любые посты и комментарии на сайте.
*   **Управление пользователями:** Через встроенную админ-панель (Django Admin) можно назначать роли, блокировать пользователей и управлять категориями/тегами.
*   **Статистика:** Отслеживание количества просмотров, лайков и комментариев у постов.

### ⚙️ Настройки профиля (для всех)
*   **Персонализация:** Загрузите аватар, укажите биографию (о себе) и измените email.
*   **Безопасность:** Смените пароль в любой момент.
*   **Управление ролью:** Переключение между ролями «Читатель» и «Автор».

## 🚀 Инструкция по запуску (Пошаговый туториал)

Для запуска проекта вам понадобятся **Docker Desktop** (для бэкенда и базы данных) и **Node.js** (для фронтенда). 

### 📥 Необходимые программы (скачать)

Если у вас ещё не установлены эти программы, скачайте их по официальным ссылкам:

*   **Docker Desktop:** [Скачать для Windows](https://docs.docker.com/desktop/install/windows-install/) | [Скачать для macOS](https://docs.docker.com/desktop/install/mac-install/) | [Скачать для Linux](https://docs.docker.com/desktop/install/linux-install/)
*   **Node.js (LTS версия):** [Скачать с официального сайта](https://nodejs.org/en/download/)

*После установки обязательно перезагрузите компьютер (особенно для Docker) и убедитесь, что Docker Desktop запущен.*
